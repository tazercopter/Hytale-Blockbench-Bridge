<span style="color:#ba372a"><strong>This mod is intended to be used with the *Hytale Bridge* Blockbench plugin installed. You cannot connect to Blockbench without it.</strong></span>

Blockbench Bridge allows to edit Hytale's Common assets (`.blockymodel` & `.pngs` files specifically) without leaving Blockbench, even on remote servers!

You can connect a Blockbench client to the server by running `/blockbench auth` in the console or as a player with the correct permissions. You will receive an authorisation key which you can input alongside the server's connection address to form a bridge and sync all files!

<sup>The mod currently occupies port `8651` on the server.</sup>
